# moonland.ai 說明中心（預覽版）

網址：https://r-ty-m1.github.io/moonland-docs/

純靜態網站，不需要安裝或建置，推到 `main` 後 GitHub Pages 會自動更新。

| 檔案 | 內容 |
| --- | --- |
| `index.html` | 頁面骨架（頂部列、左側目錄、內文區、搜尋視窗） |
| `style.css` | 配色、字體與排版。最上方的 `:root` 是深色配色，下面兩段是淺色配色 |
| `script.js` | `SECTIONS` 是目錄與分類結構；`VIEWS` 是已完成的頁面內容；`NOTION` 是待搬移頁面的原文連結 |
| `assets/` | logo（深色、淺色版）與網站圖示 |

完整的 Starlight 專案保留在 `starlight` 分支。
