# moonland.ai 說明中心

網址：https://r-ty-m1.github.io/moonland-docs/

純靜態網站，不需要安裝或建置。推到 `main` 後，GitHub Pages 約 1～2 分鐘自動更新。

## 檔案結構

| 檔案 | 內容 |
| --- | --- |
| `index.html` | 頁面骨架，並依序載入下面的檔案 |
| `style.css` | 配色、字體與排版。最上方 `:root` 是深色配色，下面兩段是淺色配色 |
| `script.js` | `SECTIONS` 是左側目錄與分類結構；其餘是顯示、搜尋、明暗模式等功能 |
| `data/*.js` | 所有文章內容，依分類分檔 |
| `data/media.js` | 圖片、影片、音訊的對照表 |
| `data/snippets.js` | 多篇文章共用的長段落（例如歌詞） |
| `assets/` | logo（深色、淺色版）與網站圖示 |

完整的 Starlight 版本保留在 `starlight` 分支。

## 新增或修改文章

1. 在對應的 `data/*.js` 新增一篇：

```js
'文章代號': {
  t: '文章標題',
  d: '一句話摘要，會出現在分類頁與搜尋結果',
  level: '新手',        // 新手／進階／團隊（選填）
  minutes: 3,           // 預估閱讀分鐘數（選填）
  models: ['FLUX.2'],   // 適用模型（選填）
  tool: '交談',         // 使用的工具（選填）
  src: 'Notion 頁面 ID', // 原文出處（選填）
  body: `
（文章內容，寫法見下方）
`},
```

2. 在 `script.js` 的 `SECTIONS` 把 `['文章代號', '目錄上顯示的名稱']` 加到想放的分類。

## 文章標記語法

| 寫法 | 效果 |
| --- | --- |
| `## 標題`、`### 小標` | 標題；`## 標題 {#h-代號}` 可指定錨點 |
| 空一行 | 分段 |
| `- 項目`、`1. 項目` | 項目清單、編號清單 |
| `**粗體**` | 粗體 |
| `[文字](#文章代號)` | 連到其他文章；`[文字](#h-代號)` 跳到本頁錨點；`https://` 開頭會開新分頁 |
| `> 提示詞` | 可一鍵複製的提示詞框，連續多行會合成一個框 |
| `\| 欄 \| 欄 \|` | 表格，第一列是標題 |
| `[i 123 說明]` | 圖片（數字是 media.js 的編號，說明可省略） |
| `[v 123 說明]`、`[a 123 說明]` | 影片、音訊 |
| `[embed 網址 說明]` | 嵌入其他網頁（例如前後比較工具） |
| `:::tip 標題` … `:::` | 綠色提示框；`:::warn` 黃色警告；`:::note` 灰色說明 |
| `:::steps` … `:::` | 編號步驟，每一步用 `@ 步驟標題` 開頭 |
| `:::row` … `:::` | 並排，每一欄用一行 `\|\|\|` 隔開 |
| `:::details 標題` … `:::` | 可展開的段落（適合長提示詞、歌詞） |
| `:::faq` … `:::` | 常見問題，每題用 `?? 問題` 開頭 |

容器可以互相包，例如步驟裡放並排圖片。

## 圖片與影片

目前的圖片、影片與音訊直接讀取 Notion 公開頁面上的檔案，所以 **Notion 頁面必須保持公開**，否則媒體會無法顯示。

正式上線前建議改成自己存放：從 Notion 匯出所有檔案，放進 `assets/media/`，再把 `script.js` 的 `mediaUrl()` 改成讀取本機路徑即可，文章不用改。

## 發布更新時

`index.html` 引用的 css、js 檔名後面有版本號（例如 `script.js?v=20261027b`）。每次更新內容後把版本號改掉，訪客的瀏覽器才會抓到新版，而不是用快取的舊檔。
