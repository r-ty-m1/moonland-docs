import { Steps, LinkCard, CardGrid } from '@astrojs/starlight/components';

<Steps>

1. **登入**：個人帳號直接登入；團隊成員請看[團隊註冊與登入方式](/account/team-signup-login/)。

2. **用交談生成第一張圖**：在交談輸入一句話，例如「一隻虎斑貓頭上戴著斗笠」。詳見[交談介紹](/chat/basics/)。

3. **調整細節**：對結果不滿意，直接在交談裡告訴 AI 要改哪裡，或用[編輯功能](/chat/edit/)。

4. **把圖片變成影片**：到[圖片生成影片（i2v）](/video/image-to-video/)讓畫面動起來。

</Steps>
