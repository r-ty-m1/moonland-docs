# 體驗帳號試算表（Google Apps Script）

說明中心的「領取體驗帳號」頁（網址 `#trial`）從這份試算表發帳號。它和回饋用的試算表**分開**（2026-11-24 使用者要求）。

- 學員在說明中心輸入課程代號 → 拿到一組還沒人領的帳號 → 按「複製帳號」「前往 moonland.ai 登入」。
- 同一個瀏覽器在同一個課程只會拿到同一組；兩個人同時按也不會拿到同一組（重複登入會把前一個人踢掉，所以這點最重要）。
- 每個梯次一個分頁；結束時間過了就不能領，隔天凌晨 1 點左右自動刪除分頁，並在「紀錄」分頁留一行摘要（不留帳號）。

## 第一次設定（只要做一次）

1. 在 Google 雲端硬碟建一份新的試算表，取名「moonland 體驗帳號」。
2. 「檔案 → 設定 → 時區」確認是 **(GMT+08:00) 台北**。
3. 「擴充功能 → Apps Script」，把編輯器裡原本的內容全部刪掉，貼上同資料夾的 `Code.gs`，按儲存。
4. 右上角「部署 → 新增部署作業」→ 齒輪選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**任何人**
   按「部署」。第一次會跳出 Google 授權視窗，兩項都勾（或按「全選」）再按繼續（只有這一次）：
   - 「查看、編輯…**這個應用程式安裝所在**的試算表」：只限這一份試算表（程式開頭的 `@OnlyCurrentDoc`）。如果寫的是「**所有** Google 試算表」，代表貼的是舊版程式，先別按，換成新的 `Code.gs` 再部署。
   - 「在你不在時執行」：每天凌晨自動刪除過期梯次要用。
   - 專案名稱可以先在 Apps Script 左上角把「未命名的專案」改成「moonland 體驗帳號」，授權視窗就會顯示這個名字。

   授權完成後，複製「網頁應用程式網址」（`https://script.google.com/macros/s/…/exec`）。
5. 回到試算表，重新整理頁面，上方會多一個「體驗帳號」選單。按「體驗帳號 → 開啟每天自動清除（只要做一次）」，再授權一次。之後每天凌晨自動執行，**不會再跳授權視窗**。
6. 把第 4 步的網址交給網站負責人，填進網站 `config.js` 的 `trialScriptUrl`，推送公司網站、重新打包靜態版。填好後左側目錄最上面才會出現「領取體驗帳號」。

確認部署成功：用瀏覽器打開那個網址，看到 `{"ok":true,"service":"moonland trial accounts"}` 就對了。

## 每次有課程

1. 「體驗帳號 → 新增梯次」，會開一個新分頁。
2. 填：
   - **單位**（例：神奕）
   - **課程代號**：已經自動產生一個 6 碼代號，可以改成自己想要的（不分大小寫）。這就是學員要輸入的。不要用帳號開頭（例 SY11241），容易被猜到。
   - **每日點數**：下拉選 3,000／5,000／6,000／10,000／20,000，也可以直接打其他數字。
   - **開始、結束**：日期加時間，例如 `2026/11/27 23:59:59`。**開始時間到了才能領**；之前輸入代號，網頁會顯示「這個課程從 11/25 00:00 開始發放」。
3. 把帳號整串貼到 **A9**：用空白、換行、逗號分隔都可以，從體驗帳號表單產生器或 Excel 表單連序號一起複製也可以。貼上後會自動整理成一列一組，序號和重複的會略過，右下角會顯示共幾組。
4. 分頁名稱會依「開始日期＋單位」自動改成「體驗1125_神奕」（改了日期或單位會跟著改）。
5. 第 7 列「狀態」會顯示共幾組、已領幾組。

**要停止發放**：勾「暫停發放」。已經領過的人回到網頁還是看得到自己的帳號，新的人領不到。
**要提早結束**：把結束時間改早，或直接刪掉分頁。
**帳號不夠**：直接在最後面接著貼，會自動整理。

## 安全

- 網頁上沒有任何帳號清單或金鑰；學員只拿得到自己那一組。
- 課程代號外流的話，拿到的人也能領。同一個瀏覽器 10 分鐘內最多試 20 次，有效期間也短，損失有限；發現被亂領就勾「暫停發放」。
- 試算表只分享給管理帳號的人；「執行身分：我」代表網頁是用部署人的權限讀寫這份試算表。

## 改了 Code.gs

在 Apps Script「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本：新版本 → 部署」，網址不會變。
