# 把回饋存進公司 Google 試算表

說明中心的回饋（「這篇有幫助嗎？」投票、意見回饋表單）可以直接存進公司 Google 帳號雲端硬碟裡的一份試算表。後台 `admin.html` 也會從這份試算表讀資料。

只要做一次，大約 10 分鐘。全程用**公司 Google 帳號**登入。

## 1. 建立試算表

1. 到 Google 雲端硬碟，新增一份 Google 試算表，取名例如「moonland 說明中心回饋」。
2. 不用自己建欄位，第一筆回饋進來時會自動建立「回饋」工作表和標題列。

## 2. 貼上程式

1. 在試算表上方選單點「擴充功能 → Apps Script」。
2. 把編輯器裡原本的內容全部刪掉，貼上這個資料夾的 `Code.gs` 全部內容，按儲存。

## 3. 設定後台密碼

1. Apps Script 左側點齒輪「專案設定」，往下找到「指令碼屬性」，按「新增指令碼屬性」。
2. 屬性填 `ADMIN_TOKEN`，值填一組你自己想的密碼（建議 12 個字以上），儲存。
3. 之後打開後台頁會要求輸入這組密碼。沒設定的話，後台讀不到任何資料。

## 4. 部署成網頁應用程式

1. 右上角「部署 → 新增部署作業」，類型選「網頁應用程式」。
2. 「執行身分」選**我**；「誰可以存取」選**所有人**（訪客不需要登入就能送出回饋）。
3. 按「部署」，第一次會要求授權：選公司帳號，按「允許」。
4. 複製畫面上的「網頁應用程式網址」（`https://script.google.com/macros/s/……/exec`）。

> 如果「誰可以存取」沒有「所有人」可選，代表公司 Google Workspace 管理員關閉了這個選項，需要請 IT 開放，否則外部訪客送不出回饋。

## 5. 把網址填進網站

打開網站的 `config.js`，把網址貼進 `googleScriptUrl` 的引號裡：

```js
window.SITE_CONFIG = {
  googleScriptUrl: 'https://script.google.com/macros/s/……/exec',
};
```

推上 GitHub 後約 1～2 分鐘生效。

## 確認是否成功

- 用瀏覽器直接打開那個網址，看到 `{"ok":true,...}` 代表部署成功。
- 到說明中心送一則意見，回到試算表應該會多一列。
- 打開 `admin.html`，輸入第 3 步設的密碼，應該看得到剛剛那則。

## 之後要改程式

改了 `Code.gs` 後，在 Apps Script 貼上新內容，然後「部署 → 管理部署作業 → 鉛筆（編輯）→ 版本選『新版本』→ 部署」。這樣網址不變，網站不用改。

## 注意

- 試算表的權限照一般 Google 檔案管理，分享給誰，誰就能看到全部回饋（含訪客留的聯絡方式）。
- 後台密碼只擋得住不知道密碼的人；要限定公司帳號才能看，最簡單的方式是直接看試算表本身。
